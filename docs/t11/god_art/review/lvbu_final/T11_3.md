# 神吕布四项表现阶段验收

状态：**PARTIAL**。本轮只处理神吕布的待机、统一攻击、出场、死亡。实机主观品质与 Medium 流畅度尚未达到可宣布通过的程度。

## 当前可看内容

双击项目根目录的 `preview_lvbu.cmd`，即可用已安装的本地依赖启动服务并打开现有验收场景；结束时双击 `STOP_PREVIEW.cmd`。此预览只读取本地资源，不调用 AI、Codex、图像生成或外部 API。端口被占用时脚本提示，不重复启动服务。

- 待机：应用分层人物遮罩，加入身体重心、视线、持戟手、头发与披风的交错循环。粒子只作辅助。
- 统一攻击：普通杀、火杀、雷杀、南蛮入侵、万箭齐发共用同一套。人物蓄力、挥戟、顿帧与收势；两个群攻对多个目标复用命中反馈。攻击图只定向生成一次透明抠图版，去掉原有棕色矩形底色，保留原动作和原图。
- 出场：人物切入、戟势与镜头推进，结束衔接待机。
- 死亡：由失力转入单膝跪落，移除了站姿残影。

现有 Level 2 无前攻击与 Level 3 神愤保留，未增加任何按牌种分开的新素材或其他神将内容。

## 画质与验证

High / Medium 按设备像素比建立 Canvas backing 尺寸，分别上限约 2 / 1.5；Medium 人物也读取原尺寸资源，高清人物与核心效果保持原始尺寸，斩击锋刃由矢量形状绘制。见 [1920×1080 统一攻击](t11_3_attack_1920.png)、[神愤](t11_3_shenfen_1920.png)、[出场](entry_preview.png)、[死亡](dying_preview.png)。待机请在预览中看动态，静态图无法验收循环。

Web 构建通过，六项直接相关的 Playwright 验收通过。1920×1080 Medium 的无界面 Chromium 定向记录位于 `performance_cinematic_1920.json`：最近一次普通攻击 37 FPS、神愤 27 FPS（此前同环境测得 27 / 26 FPS，存在波动）。本机该环境的结果**不满足**“Medium 基本流畅”，也不能替代用户在实际浏览器中的感受。继续零碎调 CSS 收益很低；若实机也有明显卡顿，后续应针对合成层与源素材进行一次明确的性能重构，而不是增加候选图或特效。
