# T11.3 神吕布阶段验收

状态：**PARTIAL**。本轮修复了 Medium 全屏演出放大低清素材的问题，并让五类牌共用一套 Level 1 戟击。人物待机与动作仍需用户在实际浏览器中判断；1920×1080 下的流畅度尚未在分辨率修复后重新量化，因此不报 PASS。

## 本地查看

双击项目根目录的 `preview_lvbu.cmd`，会启动本地后端与 Web 前端并打开现有 `/t11/god-lvbu-preview` 验收页。双击 `STOP_PREVIEW.cmd` 关闭本次启动的服务。预览只读取项目现有本地资源，不调用 AI、图像生成或外部 API。若 8000 或 5173 端口已被占用，脚本明确提示且不会重复启动。

页面中的 `Idle`、`Entry`、`Hit`、`Dying`、`Victory` 用于看人物动作。`Normal Slash`、`Fire Slash`、`Thunder Slash`、`Savage Assault`、`Archery Attack` 均播放同一套 Level 1；两个群攻按钮会对四名目标反馈。`Level 2` 为无前强化攻击，`Shenfen` 为 Level 3。`Quality` 切换 High / Medium / Low；`Reduced Motion` 可检查低动态，Esc 可跳过。

## 分辨率修复与证据

- Canvas backing 尺寸按 CSS 尺寸乘以 DPR 建立，High 上限 2、Medium 上限 1.5；明确启用高质量图像平滑。
- High 与 Medium 的全屏核心人物、神愤前景使用原尺寸 PNG，Low 才使用缩图。Medium 的神愤减少一层背景残像，保留人物和爆发前景。
- 删除跨屏粗橙色月牙；统一攻击使用矢量戟锋轨迹，随分辨率保持锐利。
- 1920×1080、浏览器缩放 100% 的 [统一攻击截图](t11_3_attack_1920.png) 与 [神愤截图](t11_3_shenfen_1920.png)。定向测试验证源图片宽度不小于显示宽度。
- Web 构建、五类牌共享演出与跳过测试、1920×1080 分辨率测试通过。完整性能回归和主观动作质量验收仍待完成。

项目内 `.venv` 和 `web/node_modules` 已安装时，一键预览无需联网。
