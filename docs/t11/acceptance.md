# T11 神将动态立绘与攻击演出验收标准（修订）

状态：**DYNAMIC PORTRAIT = PARTIAL；GOD ATTACK FX = PARTIAL**。神吕布是唯一完整样板的工作对象；其余七神将暂不扩展完整动态。画面需经用户肉眼验收，自动化通过不等于美术 PASS。

## A. 人物本体

待机必须能明显看到人物本人在动，逐项检查胸肩自然呼吸、自然眨眼、前后发独立摆动、披风与衣摆独立摆动、武器待机或能量流动、身体重心循环，以及人物、武器、前景、背景的轻微视差。粒子、光晕、烟雾仅是附加效果，不能代替任何一项。整张人物 PNG 上下浮动不算通过。若现有层无法实现，应重新制作 body、head、eyes、hair_back、hair_front、arm/weapon arm、weapon、cloth_back、cloth_front、background、front_fx 等可注册的原创层。

## B. 攻击姿态与短全屏演出

所有神将进攻牌都须让人物先做抬武器、前压、挥砍或刺击等可辨的动作，再发射攻击特效并让目标受击。普通杀须有约 0.6–1.2 秒的一级半演出：牌桌压暗与聚焦、人物切入放大、人物攻击动作、跨屏武器或能量效果、命中与 impact、迅速回桌。火杀和雷杀分别强化火焰和雷电。单独的 beam、轨迹或粒子不算通过。

二级强化技能须有约 0.8–1.5 秒的明显人物 cut-in、动态背景、专属符号、强化攻击和 impact。三级核心技能须有约 1.5–2.5 秒的真正全屏演出，支持跳过和减少动态效果，不阻塞规则引擎，且播放时规则结果已由引擎决定。神愤样板须有压暗、神吕布放大切入、暴怒挥戟、巨大战魂或戟影、赤黑冲击或裂地、多目标受击、恢复牌桌。

## F. 神吕布最终样板清单

idle 人物本体动画、blink、hair、cloth、weapon、breathing、attack pose、普通杀、火杀、雷杀、Level 2、神愤 Level 3、hit、dying、entry、victory，全部逐项通过才可标记最终完成。

## 当前实现与待验问题

- 待机已用源图坐标蒙版把身体、头部、前后发、前后披风、手臂、武器拆为独立可动组；另有闭眼帧与自然眨眼计时。它是已注册的分区动画原型，尚未达到每层都有独立修补素材的最终品质，边界和小头像效果仍需人工验收。
- 神吕布有独立的前压挥戟攻击姿态帧。预览页有普通杀、火杀、雷杀（各 0.9 秒）、二级（1.2 秒）、神愤三级（2.1 秒）的全屏样片，带 Esc/按钮跳过和 240 毫秒减少动态效果。动画由公开事件驱动，不修改规则结果。
- 牌局公开 CardUsedEvent 中，神吕布杀牌可触发一级演出，攻击轨迹延后 350 毫秒以先表现人物。二、三级只在美术预览页可触发：神将技能规则仍禁用，公开事件没有对应技能演出 cue，不能宣称牌局联动完成。
- 多目标受击、战魂或戟影的角色专属性、前景视差和死亡/入场/胜利动作仍需进一步画面验收；帧率及真实对局性能也需复核。

验收规则：只有用户肉眼明确看到“人物本身在动”和“神将攻击时出现短全屏人物攻击演出”，且神吕布清单全部完成，才可分别将 **DYNAMIC PORTRAIT** 与 **GOD ATTACK FX** 从 **PARTIAL** 改为 **PASS**。
