# 经典身份局相对强度

38/38 项目最终版本于2026-10-04按用户决定LOCKED。锁定不等于官方卡面已验证：证据保持固定revision社区档案，authority_status不变。2012/2013/四神仍为catalog only；生产65。


这是设计评估，不是模拟胜率。C下限弱，B一般经典，A强经典，S潜在高风险。未把评级用作改数值的理由。五/八人局须分别观察身份、席位、队友与真人决策；“完全上位替代”只能标风险，不能直接成立。

基准来自现行65将：于禁候选对弱势标准许褚/马超（爆发或判定不稳定）为C/B；曹操/刘备/孙权为B至A的攻防牌差；荀彧、鲁肃、贾诩、张郃为A（辅助、全场与时序收益）；神曹操、神吕布为S爆发风险，神赵云低HP/神司马懿觉醒为高技巧A/S。现有风包也含经典修订摘要，本审计不改其版本。

局规模：李儒焚城、韩当解烦、神陆逊群伤在八人收益通常更高；五人控制一个核心目标占比更大，神张辽/伏皇后/马岱特别评估；神甘宁收手牌在五人可能快速压制一个核心，也在八人更容易找到大手牌猎物。不得用“人少必强”代替验证。
