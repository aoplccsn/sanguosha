# 规则范围与边界

## 采用的范围

五人军争身份配置为主公、忠臣、两反贼、内奸。主公明置，其余身份在游戏规则要求的时点揭示。胜负与奖惩由 `IdentitySystem` 在死亡结算检查点处理：主公死亡时，若最后存活者仅为内奸，内奸胜；否则反贼胜；主公存活且反贼、内奸全部死亡，主公与忠臣胜。忠臣死亡本身不直接结束游戏。击杀反贼的击杀者摸三张；主公击杀忠臣则弃置自己的所有牌（含装备）；死亡者的牌和挂置状态统一清理，随后再处理奖惩和胜负。精确时序由事件窗口和官方规则版本在 T9 锁定。

## 卡牌与武将

基础牌：杀、闪、桃、酒、火杀、雷杀。普通锦囊：过河拆桥、顺手牵羊、无中生有、决斗、南蛮入侵、万箭齐发、桃园结义、五谷丰登、借刀杀人、无懈可击、火攻、铁索连环。延时锦囊：乐不思蜀、闪电、兵粮寸断。装备槽：武器、防具、+1 马、-1 马；具体标准/EX/军争装备清单和实体牌分布在 T10 逐张核定。

首批经典标准武将：魏（曹操、司马懿、夏侯惇、张辽、许褚、郭嘉、甄姬）；蜀（刘备、关羽、张飞、诸葛亮、赵云、马超、黄月英）；吴（孙权、甘宁、吕蒙、黄盖、周瑜、大乔、陆逊、孙尚香）；群（华佗、吕布、貂蝉）。技能采用经典原版；扩展武将依靠注册技能，不依靠核心武将分支。

## 回合与区域

回合边界：回合开始、准备、判定、摸牌、出牌、弃牌、结束、回合结束。跳阶段、额外回合、结束出牌、重复行动、摸牌/手牌上限修正均为规则效果。牌位于摸牌堆、弃牌堆、手牌、装备区、判定区、处理区或移出游戏/特殊区之一；区域转移必须有来源、去向、原因与可见性。

## 需要在实现阶段锁定的细则

“经典”在不同实体版、线上版和修订版中有差异。T1 建立 `ruleset_id` 与出处记录；T4–T10 对每张牌的文本、张数、花色、点数、目标、响应时点、无懈范围、酒与濒死、身份奖惩的准确时点逐项验收；T11–T15 对每位武将的原版技能文本逐项验收。遇到冲突，以项目选定并留档的同一规则版本为准，不在核心里混用版本。T0 不臆定未提供的逐张牌表，也不把规则争议解释为可省略功能。

## 不在首版产品范围

联网、多人真人、扩展武将、界限突破、皮肤、账号、存档/replay 播放器。架构预留可见性、注册式扩展和结构化日志，但不提前开发这些产品功能。
