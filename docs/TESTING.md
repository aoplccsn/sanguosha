# 测试策略

pytest 测核心，UI 另做少量边界测试。测试 fixture 可指定规则集、座次、身份、武将、区域中的每张实体牌、牌堆顺序、RNG 种子/脚本随机流、起始回合/阶段、体力/标记、决策脚本。测试不用 Qt；Provider 对待答请求返回 `Decision`，也可直接调用引擎 `submit`。

## 层次

| 层 | 内容 | 必要断言 |
|---|---|---|
| 模型/不变量 | 唯一牌位、合法区域、存活/死亡状态、版本号 | 每步后无重复/丢失牌；非法输入无副作用 |
| 系统单元 | 距离、移动、装备、阶段、事件顺序、伤害、判定、身份 | 给定快照与输入得精确状态及事件 |
| 结算契约 | WAIT、恢复、取消、父子帧返回、陈旧/重复 Decision | 请求唯一、栈稳定、无重复费用/效果 |
| 规则场景 | 卡牌/武将技能/身份完整场景 | 与已选规则版本案例一致 |
| 无界面整局 | 脚本 Provider 和 AI Provider 驱动终局 | 有确定胜者、无悬空请求、状态一致 |
| UI 契约 | 投影、合法请求、提交、隐藏信息 | UI 不写 State；核心无 Qt import |

## 必测场景

- 固定牌堆/种子/身份/武将/起手牌，重复运行比较事件序列与终态哈希；随机取值必须仅走注入的 RNG。
- 杀→闪成功/失败→伤害；闪/杀转化响应；非法目标/距离/次数/牌位；取消与不可取消窗口。
- 南蛮多目标，第二目标濒死并经历多人求桃，救活或死亡后按游标继续；终局时停止外层效果并正确归位处理中牌。
- 无懈套无懈至少三层，所有人放弃、不同目标范围、重复/陈旧请求拒绝。
- 普通/火/雷伤害，修正、防止、来源为空、伤后触发、铁索多目标传播，已传播集合防循环，传播中有人死亡/胜负结束。
- 判定翻牌、连续多人改判、原判定牌和最终牌分别归属、效果生效/不生效。
- 装备替换与获得、失效、马匹/武器/技能距离叠加、座次中有人死亡后的距离。
- 跳阶段、额外回合、出牌阶段多行动/结束、摸牌数和手牌上限修正。
- 主公被内奸独存时击杀、被反贼击杀、主公击杀忠臣、任意玩家击杀反贼、反贼/内奸死亡组合、死亡清理和奖惩顺序。
- 同时多技能的优先级、座次与玩家选择；触发导致新事件时不丢失/重复；新注册的测试牌和测试技能无需修改核心。
- 隐藏身份/手牌投影不泄漏；结构化日志可过滤；渲染文本不作为规则依据。

## 门槛

每阶段必须通过对应单元与集成场景、公开接口类型检查、核心与 UI 依赖检查、确定性复跑及全量回归。规则版本和案例来源随测试记录。覆盖率可辅助发现遗漏，但不能替代场景断言。对故障保留最小复现 fixture；修复时增加针对性回归测试。T0 没有业务实现，验收为设计走查：用杀闪、南蛮濒死、无懈链三条轨迹逐步证明每次 WAIT/恢复点、牌位和动作完成边界可表达。

## T2 结算回归

`tests/test_t2_engine.py` 使用测试专用 Action/Handler，覆盖简单执行、YES_NO 暂停、CHOOSE_OPTION 和 CHOOSE_PLAYER 校验、父子结果、三级嵌套暂停、非法/重复决策保留请求、注册表未知类型、确定性重跑、mock 攻击响应、mock 多目标濒死游标恢复、mock 无懈嵌套及无限循环步数保护。它们不调用 Qt，也不实现正式牌效。


## T3 回合与阶段回归

`tests/test_t3_turns.py` 覆盖六阶段完整事件顺序、两回合编号与当前玩家切换、出牌阶段连续多次请求、子 Action 再次暂停恢复、单阶段和多阶段跳过、死亡座位跳过与环形座次、死亡玩家及并发回合拒绝、非法出牌选项保持原请求、自定义阶段主体注册、确定性复跑。测试 Action 只在测试文件中定义，不触碰牌区。


## T4 基础牌回归

`tests/test_t4_basic_cards.py` 覆盖定义注册、原子批量移动、杀选择目标/闪实体响应/放弃响应/普通伤害、第二张杀拒绝与新出牌阶段重置、闪不可主动使用、桃恢复与满血拒绝、恢复上限、非法或死亡目标、非法或他人响应牌、未注册定义、五层显式栈暂停恢复、零体力濒死标记与确定性复跑。每个正常出牌分支断言处理区无残留；旧 T1–T3 测试全部回归。


## T5 可玩版回归

`tests/test_t5_match.py` 验证固定随机种子的实体牌堆、起手牌、摸牌与弃牌堆重洗、真实摸弃牌、精确多选校验、濒死桃救援与多桃救援、无人救援后死亡、所有个人区域清理、反贼奖励、主公误杀惩罚、身份胜负、死亡座次跳过、AI 决策、隐藏信息投影及无界面完整五人局。`tests/test_t5_ui.py` 在 Qt offscreen 平台验证牌桌和点击链、真人 PendingRequest 转 Decision、AI 自动推进与公开投影。另用 Qt 离屏窗口经真实按钮连续驱动一局：真人结束出牌、放弃响应或多选弃牌，四名 AI 自动行动，19 回合出现胜负。实体桌面窗口仍建议用户在本机试玩确认观感。
